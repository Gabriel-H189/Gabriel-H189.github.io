Seagull Scaring V2

Seagull Scaring V2 is a program written in Python to scare seagulls. It has a GUI that is written with either CustomTkinter or PyQt5 depending on the edition you choose.

The program is free and open-source.

There is also a menu-driven CLI known as SeagullScaringV1 that performs the same task if that's more what you like.
Lite versions of Seagull Scaring V1 and 2 are available that have no external libraries, however they are Windows only.
